# פלואו המערכת – הסבר מלא

## מי מייצר כל טוקן? מי נותן למי?

---

### טוקן 1: adminToken

| שאלה | תשובה |
|------|-------|
| **מי מייצר?** | אתה (בוחר סיסמה בעצמך) |
| **איפה?** | בדף /admin, שדה "טוקן אדמין" |
| **למי נותנים?** | לאף אחד – נשמר רק בשרת שלך |
| **למה?** | כדי שאף אחד לא יוכל לקרוא ל-init-client בלי הסיסמה |

```
אתה → בוחר סיסמה → שומר ב-/admin → נשמר ב-DB
```

---

### טוקן 2: yitApiToken

| שאלה | תשובה |
|------|-------|
| **מי מייצר?** | YIT (חברה חיצונית – שירות המיקומים) |
| **למי נותנים?** | YIT נותנים ל**מאיה תור** (לקוח שלהם) |
| **מאיה תור נותנים למי?** | **לך** – כשהם רוצים להתקין LFP |
| **למה?** | כדי שתוכל לשלוח מיקומים ל-YIT בשם מאיה תור |

```
YIT → נותן yitApiToken → מאיה תור
מאיה תור → נותן לך (במייל/טלפון/וכו') → אתה שומר ב-init-client
```

---

### טוקן 3: clientToken

| שאלה | תשובה |
|------|-------|
| **מי מייצר?** | **המערכת שלך** (init-client) |
| **מתי?** | כשאתה קורא ל-init-client עם yitApiToken |
| **למי נותנים?** | **אתה** נותן את ה-clientToken **למאיה תור** |
| **למה?** | כדי שמאיה תור יוכלו לפתוח את ה-LFP עם מזהה ייחודי (בלי לחשוף את yitApiToken) |

```
אתה → קורא init-client עם yitApiToken → המערכת יוצרת clientToken → אתה מעביר למאיה תור
```

---

## טבלה: מי נותן מה למי

| טוקן | מי מייצר | מי נותן | למי |
|------|-----------|---------|-----|
| adminToken | אתה | אתה | השרת (נשמר) |
| yitApiToken | YIT | מאיה תור | **לך** |
| clientToken | המערכת שלך | **אתה** | **מאיה תור** |

---

## הפלואו המלא – צעד אחר צעד

### צעד 1: אתה מגדיר אדמין
```
אתה → /admin → מזין adminToken → שמור
```
**תוצאה:** adminToken נשמר. מעכשיו רק עם הטוקן הזה אפשר לקרוא ל-init-client.

---

### צעד 2: מאיה תור רוצים להתקין LFP
```
מאיה תור → נותנים לך: "הנה ה-yitApiToken שלנו: abc123xyz"
אתה → POST /api/admin/init-client
      Header: Authorization: Bearer <adminToken>
      Body: { "yitApiToken": "abc123xyz" }
המערכת → יוצרת clientToken: "b380dc34-6754-4b50-8a35-cd714f201d6a"
המערכת → שומרת: clientToken ↔ yitApiToken
המערכת → מחזירה: { "clientToken": "b380dc34-6754-4b50-8a35-cd714f201d6a" }
אתה → מעביר למאיה תור: "הנה ה-clientToken שלכם: b380dc34-..."
```
**תוצאה:** מאיה תור שומרים את ה-clientToken. yitApiToken נשמר אצלך בשרת.

---

### צעד 3: מאיה תור פותחים LFP למשתמש
```
מאיה תור → בונים URL:
  /location-pin?clientToken=b380dc34-...&$city=תל%20אביב&$street=דיזנגוף
מאיה תור → פותחים חלון עם ה-URL
משתמש → רואה מפה, מסמן נקודה, לוחץ "שמור מיקום"
```
**תוצאה:** המיקום נשלח ל-YIT.

## סיכום בקצרה

| מה | פרטים |
|----|--------|
| **adminToken** | אתה בוחר, שומר ב-/admin. משמש רק אותך. |
| **yitApiToken** | מאיה תור נותנים **לך**. אתה שומר ב-init-client. |
| **clientToken** | המערכת יוצרת. **אתה** נותן **למאיה תור**. הם משתמשים ב-URL. |
